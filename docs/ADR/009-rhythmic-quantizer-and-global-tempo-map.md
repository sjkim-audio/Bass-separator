# [ADR-009] 리듬 양자화를 위한 총체적 템포 맵(Global Tempo Map) 및 동적 격자 스냅 도입

* **Status:** Accepted
* **Date:** 2026-03-01 (Retroactively Documented & Refined for Phase 7)
* **Related Documents:** [Transcription_Phase7_Quantizer_Architecture.md](../Transcription_Phase7_Quantizer_Architecture.md)

## 1. Context (배경)

피치 트래킹(Phase 6) 단계에서 추출된 데이터는 밀리초(ms) 단위의 물리적 절대 시간(Absolute Time)을 갖는다. 이를 악보로 렌더링하기 위해서는 오디오의 BPM을 추정하고 음악적 박자(Grid)에 맞게 정규화(Normalize)하는 양자화(Quantization) 과정이 필수적이다.

초기 양자화 설계에서는 다음과 같은 도메인 특화 문제들이 발생했다.
1. **위상 불연속성 (Phase Discontinuity):** 파트별로 기준이 되는 트랙(어떤 구간은 드럼, 어떤 구간은 베이스)을 스위칭하며 템포를 추출하려 했으나, 경계선에서 박자가 어긋나며 악보가 밀리는 현상이 발생했다.
2. **엇박자(Syncopation) 오인:** 베이스 라인은 정박(Downbeat)보다 엇박 연주가 잦다. 베이스 트랙 단독으로 BPM을 추출할 경우, 비트 트래커가 엇박을 정박으로 오인하여 전체 악보의 위상이 180도 뒤집히는 치명적 오류가 발생했다.
3. **리듬 훼손 및 시스템 충돌:** 16분음표 강제 스냅으로 인해 3연음이 기계적으로 뭉개졌으며, 온셋이 밀집된 구간에서 앞 노트의 꼬리를 자르다 지속 시간이 음수(Negative Duration)로 역전되어 렌더러가 크래시되는 논리적 결함이 발견되었다.

## 2. Decision (결정)

물리적 시간을 음악적 시간으로 변환하기 위해, 곡 전체를 관통하는 **총체적 템포 맵(Global Tempo Map)**을 구축하고 수학적 최적화에 기반한 **동적 격자 스냅(Dynamic Grid Snapping)** 알고리즘을 도입한다.

1. **단일 진실 공급원 (Single Source of Truth):** 템포 추출의 1순위 타겟을 베이스가 제외된 `Bassless MR` 트랙으로 고정한다. (MR이 없는 베이스 단독 DI 음원일 경우에만 Fallback으로 베이스 트랙을 참조한다.)
2. **동적 해상도 평가 (Dynamic Grid Evaluation):** 추정된 다운비트 배열 $B = [t_1, t_2, \dots, t_n]$ 을 기반으로 특정 시간 $t$가 속한 로컬 비트 간격을 찾는다. 이때 무조건 16분음표($N=4$) 격자를 쓰지 않고, 해당 박자 내의 온셋 분포를 분석하여 8분 3연음($N=3$)과 16분음표($N=4$) 중 오차 제곱합(SSE, Sum of Squared Errors)이 더 적은 해상도를 동적으로 채택한다.
   $$G_j = B_k + \frac{j}{N}(B_{k+1} - B_k)$$
   이후 물리적 온셋/오프셋 시간과 격자점 간의 1차원 절댓값 차이($|t - G_j|$)가 가장 짧은 위치로 노트를 스냅(Snap)한다.
3. **단선율 강제화 (Monophonic Enforcer) 및 버그 방어:** 양자화된 오프셋 $E'_i$ 가 다음 노트의 온셋 $O'_{i+1}$ 을 침범할 경우, 지속 시간이 음수로 역전되는 크래시를 막기 위해 하한선(Clamp) 수식을 적용하여 강제 절단한다.
   $$E'_i = \max(O'_i + 0.01, \min(E'_i, O'_{i+1} - \delta)) \quad (\text{단, } \delta=10\text{ms})$$
4. **그리드 기반 병합 (Grid-based Merging):** 동일한 피치를 가지며 '동일한 양자화 격자(Grid Index)'에 스냅된 노트들만 기계적 노이즈로 간주하여 병합한다.

## 3. Considered Options (검토된 대안들)

1. **구간별 파트 스위칭 트래킹:** 드럼이 나오는 곳은 드럼을, 드럼이 쉬는 곳은 베이스를 참조해 BPM을 이어 붙이는 방식. (경계선 위상 불일치로 기각)
2. **베이스 트랙 최우선 트래킹:** 베이스 채보 프로그램이므로 베이스를 기준으로 박자를 찾는 방식. (베이스 특유의 당김음/엇박을 정박으로 오판하여 악보가 붕괴되므로 기각)
3. **MR 중심의 Global Tempo Map + 유연한 그리드 스냅:** 현대 음악의 정박 기준은 백킹 트랙에 있다는 점을 전제로 단일 템포 맵을 그리고, 박자 단위로 3연음/16분음표 격자를 유동적으로 선택하는 방식. (최종 채택안)

## 4. Rationale (의사결정 근거)

### 4.1. 위상 왜곡(Phase Distortion) 방어
베이스 연주가 싱코페이션(엇박)을 주도하더라도, 보컬/기타/드럼이 포함된 MR 트랙의 어택(Onset) 에너지를 종합하면 곡의 진짜 정박(Downbeat)을 훨씬 안정적으로 추론할 수 있다. MR을 우선 참조함으로써 베이스 엇박자에 비트 트래커가 속아 넘어가는 위상 반전 에러를 원천 차단했다.

### 4.2. 3연음 및 셔플 그루브 보존 (SSE 동적 평가)
모든 박자를 16분음표로 강제하면 스윙, 바운스 리듬이 기계적으로 훼손된다. 각 비트마다 $N=3$과 $N=4$ 격자에 대한 오차 제곱합(SSE Cost)을 산출하여 승자를 채택함으로써, 연산 병목 없이 3연음 그루브를 유연하게 방어했다.

### 4.3. 템포 의존적 다이내믹스 보존
기존 50ms 이하 절대 시간 기준의 병합 룰은 고속 펑크(Funk) 연주 시 의도된 16분음표 스타카토 연타를 단일 장음으로 뭉개버리는 부작용이 있었다. 격자(Grid) 단위로 병합 조건을 격상함으로써, 템포가 빠를 때는 병합 허용 시간도 자연스럽게 짧아져 음악적 다이내믹스가 훼손되지 않도록 조치했다.

## 5. Consequences (결과)

* **Positive:**
  * 엇박자 연주 구간에서도 정박의 기준선이 흔들리지 않아 악보의 리듬 표기가 정확해졌다.
  * 음수 지속시간(Negative Duration)으로 인한 파이프라인 크래시 위험이 수학적 하한선(Clamp) 로직을 통해 원천 차단되었다.
  * SSE 동적 평가 및 그리드 기반 병합을 통해 3연음(Triplet)과 고속 스타카토의 음악적 표현력이 온전히 보존되었다.
* **Negative & Limitations:**
  * 밴드가 멈추고 베이스 연주자가 의도적으로 템포를 급격히 늦추거나 당겨 치는 '루바토(Rubato)' 연주 시, 비트 트래커의 관성 보간망을 벗어나 악보 양자화가 완전히 붕괴될 수 있다.
