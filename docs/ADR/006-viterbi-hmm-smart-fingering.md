# [ADR-006] 탐욕(Greedy) 알고리즘 대신 Viterbi HMM 기반 최적 운지법 채택

* **Status:** Accepted
* **Date:** 2026-03-01 (Retroactively Documented for Phase 3)
* **Related Documents:** [Transcription_devlog.md](../devlogs/Transcription_devlog.md), [Viterbi_Math_Model.md](../Viterbi_Math_Model.md)

## 1. Context (배경)

오디오에서 추출된 피치(Hz)를 베이스 기타 지판의 물리적 위치(String, Fret)로 매핑하는 과정에서, 초기(Phase 2)에는 탐욕(Greedy) 알고리즘을 사용했다. 즉, 특정 피치를 표현할 수 있는 여러 지판 위치(후보군) 중 **무조건 가장 프렛 숫자가 낮은(개방현 쪽에 가까운) 위치**를 선택하도록 하드코딩했다.

하지만 베이스 기타는 동일한 음을 여러 현에서 낼 수 있는 이음동음(Enharmonic) 악기이다. 단일 음표 기준의 탐욕 알고리즘을 적용한 결과, 다음과 같은 한계가 드러났다.
1. **부자연스러운 동선 (String Skipping):** 1번 줄(G현) 5프렛에서 연주하는 것이 자연스러운 음을, 더 낮은 숫자를 찾기 위해 굳이 3번 줄(A현) 15프렛으로 강제 배정하는 등 연주자의 손이 지판 양끝을 급격히 오가야 하는 물리적으로 까다로운 동선이 빈번하게 생성되었다.
2. **톤(Tone) 일관성 저하:** 같은 프레이즈 내에서도 인접한 음을 치기 위해 얇은 줄과 굵은 줄을 무분별하게 오가며, 결과적으로 베이스 라인의 음색(Timbre) 일관성이 훼손되는 현상이 발생했다.

## 2. Decision (결정)

베이스 연주자의 **생체역학적 손가락 이동 제약(Biomechanical Constraints)**을 수학적으로 모델링하여, 전체 연주 프레이즈 단위에서 총 이동 비용(Cost)을 최소화하는 **Viterbi HMM(Hidden Markov Model) 기반 동적 계획법(Dynamic Programming) 디코더**를 도입한다.

1. **상태 공간 (State Space):** 각 시점 $t$에서 해당 피치를 낼 수 있는 모든 (String, Fret) 쌍을 은닉 상태(Hidden State) 후보군으로 설정한다.
2. **전이 비용 함수 (Transition Cost Function):** 이전 상태에서 현재 상태로 이동할 때 발생하는 생체역학적 제약을 다음 다섯 가지 페널티(및 보너스)의 합으로 산출한다.
   * **수직 이동 비용 ($W_s$):** 줄을 건너뛰는(String Skipping) 물리적 거리 페널티.
   * **수평 이동 비용 ($W_f$):** 프렛을 좌우로 이동하는 거리 페널티. 일정 간격(`shift_threshold`)을 초과할 경우 손의 범위를 벗어난 것으로 간주하여 2차 함수로 지수적 증가를 부여한다.
   * **하이 프렛 페널티:** 포지션이 높을수록 팔과 손목에 긴장이 더해지는 물리적 특성을 반영한 기본 유지 비용.
   * **개방현 이질감 페널티:** 닫힌 현(Fretted)에서 연주하다 갑자기 개방현(0 프렛)으로 넘어갈 때 발생하는 톤 변화(Tone Shift) 페널티. (반대로 개방현에서 닫힌 현으로 도약할 때는 가상 중립 포지션 기반의 거리 페널티 부여)
   * **동음 유지 보너스 (Same Position Bonus):** 동일한 피치가 반복될 때 불필요하게 운지를 바꾸는 플래핑(Flapping)을 억제하기 위한 음수(-) 페널티.
3. **시간 가중치 ($\Delta t$):** 두 음표 사이의 물리적 간격(Duration)이 짧을수록 포지션 이동이 어렵다는 점을 반영하여, 시간의 역수에 비례하여 페널티를 동적으로 스케일링한다. 단, 시간이 아무리 길어져도 최소한의 물리적 도약 비용이 보장되도록 하한선(Baseline Cost)을 두어 연산의 왜곡을 방지한다.

## 3. Considered Options (검토된 대안들)

1. **Greedy (Lowest Fret Priority):** 무조건 0프렛에 가장 가까운 운지를 선택하는 방식. 연산이 단순하나 연주 편의성이 심각하게 훼손된 악보를 도출하여 기각했다.
2. **Heuristic Rule-based:** "3프렛 이상 벌어지면 다른 줄을 쓴다"와 같은 조건문(If-else)을 다수 하드코딩하는 방식. 다양한 연주 엣지 케이스에 대처하기 어렵고 코드가 스파게티화될 우려가 있어 기각했다.
3. **Viterbi Algorithm (DP):** 전체 프레이즈의 맥락(Context)을 파악하여, 정의된 비용 함수 내에서 전역 최적 경로(Global Optimum Path)를 산출하는 방식. (최종 채택안)

## 4. Rationale (의사결정 근거)

### 4.1. 국소 최적해(Local Optimum)의 한계 돌파
탐욕 알고리즘은 당장 눈앞의 단일 음표에 대해서는 최적일지 모르나, 다음 음표로 넘어가기 위한 손의 포지션을 고려하지 않아 결과적으로 매우 비효율적인 동선으로 이어질 수 있다. 비터비 알고리즘은 곡의 끝(또는 일정 윈도우)까지 DP 테이블을 전개한 뒤 백트래킹(Back-tracking)하므로, 현재 음표에서는 약간 불편한 위치를 선택하더라도 전체 연주 흐름을 부드럽게 유지하는 '전역적 시점의 포지션 배정'이 가능하다.

### 4.2. 속주(Trill) 구간의 물리적 한계 반영
시간 가중치($1/\Delta t$) 개념은 오직 오디오 분석을 통해 얻은 물리적 시간 데이터(`events[t].time`)가 존재해야만 구현 가능하다. 16분음표 이상의 빠른 속주 구간에서는 수평 이동(프렛 슬라이드) 페널티가 폭증하도록 설계하여, 자연스럽게 손을 특정 프렛 구간에 고정한 채 줄만 위아래로 튕기는(String Crossing) 포지션 플레이를 알고리즘 스스로 산출하도록 유도했다.

### 4.3. 구조적 확장성 및 최적화 잠재력
현재의 전이 비용(Transition Cost) 계수들($W_f=1.0, W_s=2.0$)은 개발자의 경험에 기반한 휴리스틱 수치이다. 하지만 디코더에 HMM 아키텍처를 확립해 둠으로써, 향후 대규모 타브 악보 데이터셋(Ground Truth)을 확보했을 때 이 가중치 행렬을 베이지안 최적화(Bayesian Optimization)나 역강화학습을 통해 데이터 기반으로 정교하게 튜닝할 수 있는 구조적 기반을 마련했다.

## 5. Consequences (결과)

* **Positive:**
  * 불필요하고 급격한 줄 바꿈 현상이 유의미하게 감소하였으며, 단일 음표가 아닌 프레이즈 단위로 포지션을 유지하는 보다 자연스러운 운지법이 산출됨을 관찰했다.
  * 시간 가중치 적용을 통해, 빠른 연주 구간에서 무리한 프렛 이동을 억제하고 안정적인 수직 동선(String Crossing)을 우선적으로 제안하게 되었다.
* **Negative & Limitations:**
  * 전체 이벤트 길이($N$)와 각 이벤트의 상태 후보군 수($S$)에 대해 $O(N \cdot S^2)$의 시간 복잡도를 가지므로 탐욕 알고리즘 대비 이론적인 연산량이 증가한다.
  * **Mitigation:** 베이스 기타의 특성상 단일 음의 후보군 $S$가 보통 4개(4현 베이스 기준)를 넘지 않으므로, 5분 길이의 곡(약 1,000개 노트)도 수 밀리초 이내에 연산이 완료되어 전체 파이프라인의 레이턴시에 실질적인 병목을 주지 않는다.
  * **Future Work:** 현재 산출된 경로가 '수학적' 최적해일 뿐, 모든 스타일의 베이시스트가 동의하는 '실제' 최적 운지라고 단정할 수는 없다. 객관적 검증을 위한 실제 타브 악보 기반의 데이터 튜닝이 후속 과제로 남아있다.
