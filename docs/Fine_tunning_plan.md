# Fine-Tuning Strategy & Training Plan

본 문서는 htdemucs 모델의 베이스 트랙 분리 성능을 향상시키기 위한 파인튜닝(Fine-tuning) 계획과 구조적 안전망을 기록합니다.

## 1. Objective (파인튜닝 목표)
특정 장르(메탈 등)나 특정 주법(슬랩 등)에만 국한된 전문가 모델을 만드는 것이 아닌, **어떤 환경의 오디오 소스에서도 베이스를 안정적으로 분리해내는 '범용 모델(General-purpose Model)'의 정밀도를 끌어올리는 것**이 최종 목표입니다. 

직접 구축한 하드 케이스(고음역대 간섭, 강한 어택 노이즈 등) 데이터셋을 활용하여 모델의 취약점을 보완하되, 모델이 기존에 학습한 넓은 음악적 범용성(치명적 망각, Catastrophic Forgetting)을 잃지 않도록 철저히 통제된 환경에서 학습을 진행합니다.

## 2. Core Strategies (치명적 망각 방지 전략)

범용성을 유지하며 성능을 끌어올리기 위해 파이토치(PyTorch) 학습 루프에 다음과 같은 3가지 안전장치를 도입합니다.

* **2.1. Data Rehearsal (데이터 믹스 훈련)**
    * 커스텀 증강 데이터셋(직접 녹음 및 이펙팅 처리된 데이터)에만 모델이 과적합(Overfitting)되는 것을 방지합니다.
    * 기존의 광범위한 상업 음원이 포함된 공개 데이터셋(예: MusDB18)을 가져와, `[커스텀 데이터 30% + 범용 데이터 70%]`의 비율로 섞어 미니배치(Mini-batch)를 구성합니다. 이를 통해 모델은 새로운 약점을 극복하면서도 기존의 지식을 리허설(복습)하게 됩니다.

* **2.2. Layer Freezing (선택적 가중치 동결)**
    * Demucs 네트워크의 모든 신경망 층을 재학습시키면 기존에 잘 잡혀있던 분리 체계가 붕괴할 위험이 있습니다.
    * 오디오의 보편적인 음향 특징을 추출하는 앞단(Encoder)의 가중치는 완전히 동결(Freeze)하고, 베이스의 최종적인 질감을 복원하는 뒷단(Decoder)이나 병목(Bottleneck) 구간의 파라미터만 미세하게 업데이트하도록 모델 층을 분리하여 학습합니다.

* **2.3. Low Learning Rate & Early Stopping (학습률 제어)**
    * 기존의 안정적인 가중치 텐서가 크게 요동치지 않도록, 초기 모델을 학습시킬 때보다 현저히 낮은 수준의 초저도 학습률(Learning Rate)을 설정하여 점진적인 방향으로만 튜닝합니다.
    * 검증 데이터셋(Validation Set)의 SDR 지표가 하락하기 시작하면 즉각 학습을 중단(Early Stopping)하여 과적합을 차단합니다.

## 3. Training Pipeline (향후 진행 로직)
1.  **데이터 로더 구성**: 커스텀 데이터와 범용 데이터를 혼합 출력하는 PyTorch `Dataset` 및 `DataLoader` 모듈 작성.
2.  **모델 레이어 세팅**: `htdemucs` 사전 학습 가중치 로드 및 특정 레이어 `requires_grad = False` 처리.
3.  **지표 트래킹**: Weights & Biases (W&B)를 연동하여 에포크(Epoch)별 Loss 및 분리 지표 실시간 시각화.
