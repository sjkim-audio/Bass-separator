## Phase 3: Viterbi HMM 기반 베이스 기타 최적 운지법(Smart Fingering) 수학적 모델링

이 문서는 베이스 기타의 타브 악보 생성을 위해 도입된 은닉 마르코프 모델(HMM) 기반 Viterbi 디코딩 알고리즘의 핵심 수학적 원리와 비용 함수(Cost Function) 설계를 상세히 정의합니다.

### 1. 문제 정의 및 모델링 개념 (Problem Formulation)

베이스 기타는 하나의 음정(Pitch)을 여러 개의 위치(String, Fret)에서 연주할 수 있는 **다중 포지션(Multi-position) 악기**입니다. 따라서 단순히 추출된 음정(Observation)을 악보로 옮기는 것을 넘어, 연주자의 물리적 피로도와 이동 동선을 최소화하는 최적의 운지 경로를 찾아야 합니다.

이를 해결하기 위해 문제를 **은닉 마르코프 모델(Hidden Markov Model, HMM)**로 정의하고, **동적 계획법(Dynamic Programming)**의 일종인 **Viterbi 알고리즘**을 사용하여 전역 최적해(Global Optimum)를 탐색합니다.

* **관측 시퀀스 (Observations):** 시간 $t$에 따른 MIDI 노트의 배열 $O = (o_1, o_2, \dots, o_T)$
* **은닉 상태 (Hidden States):** 특정 노트 $o_t$를 연주할 수 있는 가능한 모든 운지 위치 집합 $C_t = \{x_{t,k}\}_{k=1}^{K_t}$. 여기서 상태 $x$는 줄 인덱스와 프렛 번호의 튜플 $x = (s, f)$입니다.
* **목적 함수 (Objective Function):** 전체 연주 시퀀스에서 발생하는 **전이 비용(Transition Cost)**의 총합을 최소화하는 상태 시퀀스 $X^* = (x_1^*, x_2^*, \dots, x_T^*)$를 찾는 것입니다.

$$X^* = \arg\min_{x_1 \dots x_T} \sum_{t=2}^{T} T(x_{t-1}, x_t, \Delta t)$$

여기서 $T(u, v, \Delta t)$는 상태 $u = (s_1, f_1)$에서 상태 $v = (s_2, f_2)$로 시간 $\Delta t$ 내에 이동할 때 발생하는 생체역학적 비용 함수입니다.

---

### 2. 생체역학적 비용 함수 설계 (Transition Cost Function)

초기 모델의 단순한 기하학적 거리 산정 방식을 폐기하고, 베이스 연주의 실제 인간 공학적 특수성(One Finger Per Fret 원칙, 관용적 패턴, 비행 시간)을 수학적으로 수치화했습니다. 총 전이 비용은 4가지 컴포넌트의 합으로 계산됩니다.

$$T(u, v, \Delta t) = C_{physical} + C_{open} + C_{height} + C_{stay}$$

#### 2.1. 동적 시간 가중치 (Dynamic Time Multiplier)
물리적 이동 페널티는 두 음표 사이의 시간 간격 $\Delta t$가 짧을수록 기하급수적으로 증가해야 합니다. 0으로 나누는 오류를 방지하고, 템포가 무한히 느려지더라도 지판을 가로지르는 최소한의 물리적 도약 비용이 보장되도록 하한선 상수 $k$를 포함합니다.

$$M_{\Delta t} = \frac{1}{\max(\Delta t, 0.05)} + k$$

#### 2.2. 상호 배타적 물리 이동 계층화 ($C_{physical}$)
지판 내의 모든 수평/수직 이동은 인체공학적 난이도에 따라 **3가지의 배타적 상태(Mutually Exclusive Tiers)**로 엄격히 분리되어 산정됩니다. 이는 알고리즘이 무의미한 기교를 배제하고 안정적인 앵커(Anchor) 블록을 찾도록 유도합니다.

* **Tier 1: 관용적 폼 (Idiomatic Shape)**
  * **조건:** 줄 차이가 1~2개이고 프렛 차이가 2개인 옥타브/5도 도약 형태.
  * **로직:** 손목 이동 없이 손가락만 뻗어 연주하는 생체역학적 이점을 반영하여 수직/수평 이동 페널티를 대폭 감면($70\%$, $50\%$)합니다.
* **Tier 2: 스케일 블록 내 이동 (In-Block Move)**
  * **조건:** Tier 1이 아니며, 프렛 이동 거리($d_f$)가 3 이하인 경우.
  * **로직:** 4개의 손가락이 커버하는 기본 포지션 범위(One Finger Per Fret) 내의 움직임입니다. 팔을 고정한 채 연주가 가능하므로 수평 이동 비용을 크게 감면($70\%$)하고, 앵커 고정에 따른 수직 이동 안정성을 소폭 감면($20\%$)합니다.
* **Tier 3: 포지션 시프트 (Position Shift)**
  * **조건:** 프렛 이동 거리($d_f$)가 3을 초과하는 경우.
  * **로직:** 손목과 팔 전체가 지판을 미끄러져야 하므로 감면 없이 기본 거리에 비례한 비용을 부과하며, 한 뼘 커버 임계값 초과 시 비선형 페널티를 추가합니다.

**비대칭 시간 결합 (Asymmetric Time Coupling)**
고속 연주 시 팔 전체를 움직이는 수평 이동은 손가락만 뻗는 수직 이동보다 물리적으로 훨씬 불리합니다. 이를 수식에 비대칭적으로 반영합니다.
$$C_{physical} = \left( C_{fret} \times M_{\Delta t} \right) + \left( C_{string} \times \sqrt{M_{\Delta t}} \right)$$

#### 2.3. 개방현 비행 시간 역학 (Flight-time Model: $C_{open}$)
개방현 연주 시 왼손은 특정 프렛에 묶이지 않고 지판 위를 자유롭게 이동할 수 있는 비행 시간(Flight Time)을 얻습니다.
* **Case A (닫힌 현 $\rightarrow$ 개방현):** 음색의 이질감(Timbre Inconsistency) 억제를 위한 고정 페널티를 부과합니다.
* **Case B (개방현 $\rightarrow$ 닫힌 현):** 개방현이 울리는 시간($\Delta t$)이 길수록 손의 이동은 완전히 자유로워지므로 페널티가 $0$에 수렴합니다. $\Delta t$가 극도로 짧은 상황에 한해서만 넥 중간(5번 프렛)을 앵커로 삼아 제약을 부과합니다.
$$C_{open} = \max(0, f_2 - 5) \times 0.2 \times \frac{1}{\Delta t}$$

#### 2.4. 환경 요인 ($C_{height}, C_{stay}$)
* **하이 프렛 임계 페널티 ($C_{height}$):** 무조건 낮은 프렛으로 손을 끌어내리던 기하학적 중력 오류를 배제하고, 옥타브 분기점인 12프렛을 초과하여 하이 프렛으로 진입할 때만 점진적 페널티를 부과합니다.
  $$C_{height} = \max(0, f_2 - 12) \times W_{high}$$
* **동음 유지 보너스 ($C_{stay}$):** 피치가 같은 연속된 음을 칠 때의 불필요한 위치 변경(Flapping)을 억제하기 위해 가중치 보너스 $-W_{stay}$를 부여합니다.

### 3. Viterbi 디코딩 과정 (Viterbi Decoding Process)

파이썬 코드의 `viterbi_decode` 메서드는 다음 단계를 거쳐 최적해를 연산합니다.

1.  **State Space 초기화:** 각 시점 $t$마다 `get_fret_candidates`를 호출하여 유효한 운지 후보 $C_t$ 배열 생성.
2.  **DP 테이블 할당:** 누적 비용 테이블 $DP[t][i]$ 및 역추적 테이블 $Backpointer[t][i]$ 초기화.
3.  **Forward Pass (순방향 연산):**
    $$DP[t][i] = \min_{j} \left( DP[t-1][j] + T(x_{t-1, j}, x_{t, i}, \Delta t) \right)$$
    해당 연산을 $t=1$부터 $T$까지 반복하여 점화식을 계산.
4.  **Backward Pass (역추적):** 마지막 시점 $T$에서 최소 비용 인덱스를 선택하고, $Backpointer$를 역순으로 거슬러 올라가며 전역 최적 경로(Global Optimal Path)를 복원.

### 4. 도메인 지식 연계를 통한 모델의 수학적 교정 (Refinements)

본 섹션은 초기 수학적 모델링이 안고 있던 기계적 맹점을 실제 베이스 기타 연주 도메인 지식(Domain Knowledge)을 통해 어떻게 교정했는지 그 인과율을 명시합니다.

#### 4.1. 목적 함수 제약 조건의 엄밀화
전역 최적해를 구하는 목적 함수는 방출 비용(Emission Cost)에 대한 제약을 수반해야 합니다. 음정 $o_t$를 낼 수 있는 유효 프렛 집합 $C_t$ 외의 상태는 무한대의 비용을 갖는 것으로 간주하여 수학적 무결성을 확보했습니다.
$$X^* = \arg\min_{x_1 \dots x_T} \sum_{t=2}^{T} T(x_{t-1}, x_t, \Delta t) \quad \text{subject to } x_t \in C_t$$

#### 4.2. 이중 감면(Double Discounting) 방어를 위한 계층 분리
최적화 과정에서 '관용적 옥타브 패턴'과 '스케일 블록 연주'에 각각 디스카운트를 중복 부여할 경우, 두 조건의 교집합에서 페널티가 비정상적으로 $0$에 수렴하는 비약이 발견되었습니다. 이를 방어하기 위해 이동 양상을 3개의 층위로 분리하는 배타적 계층(Mutually Exclusive Tiers) 구조를 도입, 알고리즘이 억지로 옥타브를 남발하며 비용을 삭감하려는 기형적인 오작동을 차단했습니다.

#### 4.3. 템포와 생체역학의 비대칭성 모순 해결
초기 모델은 16비트 고속 연주 시 수평 도약을 피하고자 줄을 3개씩 건너뛰는 비상식적인 운지를 채택했습니다. 인간의 관절 구조상 수평 도약(어깨/팔꿈치)과 수직 도약(손가락)의 요구 에너지가 다름에 착안하여, 시간 가중치 $M_{\Delta t}$를 축별로 비대칭 결합($\sqrt{M_{\Delta t}}$ 적용)함으로써 기계적 제약과 실제 연주 가능성 간의 모순을 완전히 해소했습니다.
